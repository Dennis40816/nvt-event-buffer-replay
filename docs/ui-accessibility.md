# UI interaction and accessibility

The desktop workstation defaults to the high-contrast dark palette and can toggle a reviewed light palette from the header or command palette. Semantic brushes adapt every main surface. Light mode uses a pale Paint canvas and its own grid, axis, label, and contact contrast instead of retaining the dark canvas.

Press `Ctrl+K` to open the command palette. Global shortcuts are:

- `Ctrl+O` load a capture; `Ctrl+S` save review; `Ctrl+E` export analysis;
- `Space` play/pause; `Left`/`Right` step; `Shift+Left`/`Shift+Right` jump 10 logical frames; `Home`/`End` seek bounds;
- `[`/`]` decrease/increase replay speed; `1` returns to `1×`;
- `I`/`O` remain keyboard shortcuts for loop bounds; `M` marks the current frame or loop range; `L` shows or hides the Paint legend;
- `Escape` closes the command palette.

The bottom `Keys` button opens the same catalog. Keyboard matching, transport
tooltips, and the four palette modules all use `ReplayShortcutCatalog` as one
source of truth.

Primary controls expose explicit UI Automation names. Review rows always print `Alarm`, `Error`, `Warning`, or `Info`; ASIL and QA states are textual and never rely on color alone. Status changes are a polite live region. Standard Avalonia focus order, keyboard activation, high-DPI scaling, and Windows text rendering remain enabled. Body text is normally 13–14 px, important controls are 14 px, compact fields/selects are 34 px high, and primary/icon buttons are 36 px high with centered content. The window is usable at its 1180×720 minimum, and startup caps its height to the active screen working area with a small safety margin so the transport never opens behind the taskbar. An empty Review Queue starts collapsed even on a wide screen; otherwise it collapses automatically below 1400 pixels. Inspector collapses below 1240 pixels unless the operator explicitly chooses a rail state. Its expanded width can be resized from 320 to 520 pixels and is restored after collapsing; the collapsed rail still exposes solid Finger/Glove/Palm glyph counts and a textual ASIL state.

Inspector presents one semantic source of truth instead of repeating Frame Summary and Decoded fields. The fixed header prioritizes logical frame, selected replay clock, CRC, ASIL, and All Break only when asserted. The Contact list is capped at the supported ten IDs, uses the same stable ID colors and solid type glyphs as Paint, prints type/state/X/Y, and highlights the selected ID on the canvas. Lower-detail tabs separate Protocol and I²C transport, semantic Raw byte layout, and human Review actions; adapter-specific source fields, source locations, stable ID, and hash remain under an on-demand Source identity disclosure. Copy frame summary and previous/next finding controls remain keyboard-accessible buttons with explicit automation names.

Paint keeps every contact's point, coordinate label, and trajectory in one stable color. Labels choose among eight anchors, avoid every visible point and prior label when possible, use a leader line, and split ID/state from X/Y coordinates. Finger, Glove, Palm, and Reserved glyphs remain textual in the legend so type is not communicated by shape alone. Legend Auto mode scores contact density across the complete capture, chooses the least occupied corner once, and remains stable while frames advance; operators can pin a corner, click the legend to compact it, or use `L` and Canvas Settings to show or hide it. `Recent` exposes a 2–120 frame history length, `Until Break` clears a contact after its Break, and `Persistent` keeps completed gestures without joining a later reuse of the same ID. Canvas overlays expose independent X/Y reversal, subtle/strong coordinate grid, zoom, Fit, and a view-only Clear action.

The replay timeline uses a thin neutral track that strengthens on hover, a white playhead, lime logical/loop state, muted physical progress, and amber evidence. Physical, Logical, and Evidence counts sit beside their own tracks instead of in a detached summary. The control row groups transport, clock/speed, loop/annotation, and view preferences in that order. Loop bounds are direct draggable brackets with a shaded selected range; the `Loop` toggle creates a one-second default range and `Clear` removes it. No default platform slider thumb is exposed. A marker can be removed from the explicit Inspector action, the full Review marker row context menu, or the timeline context menu at any frame covered by that marker; right-clicking the timeline never seeks or captures the pointer.

Decode Configuration is confirmation-driven and has no redundant Decode button. After indexing, selecting Common `0x82`–`0x85` decodes immediately. Desay `0x97` remains in Raw Explorer until an IC profile and Standard/Benz Palm option are both confirmed. For reproducible desktop QA, a capture may be opened with an explicit decoder choice: `Nvt.Replay.Avalonia capture.txt --event-version 0x83`. Desay 0x97 additionally requires both `--register-profile <family>` and `--palm-profile Standard` or `--palm-profile Benz-Palm`. These options never guess semantic configuration or assume NT51927's Event Buffer base.

CI runs Skia-backed Avalonia headless tests that open the real `MainWindow`, render dark and light frames, verify compact alignment and responsive rail defaults, and complete a KingstVIS/Common `0x83` load-to-auto-decode round trip. Manual release UI checks still cover pixel-level dark/light review, command palette focus/dismissal, keyboard replay, all trajectory modes, and a full capture/decode/Paint round trip. No telemetry, update checker, upload, or network client exists in the application.
